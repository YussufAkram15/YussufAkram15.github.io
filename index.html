secure_vault.py featured project

Secure Vault — File Encryption Utility

team of 5 CLI + GUI: my own build

A hybrid encryption tool for encrypting and decrypting local files, built to understand key management rather than just call a library. AES handles fast block encryption of file data; RSA wraps the AES key for secure exchange. Ships as a dark-themed GUI using the Web Crypto API alongside a Python CLI, with attention to safe file-permission handling during read/write so plaintext never lingers longer than it has to.

PythonAES / RSAWeb Crypto APIHTML / CSS / JS

Operating Systems course + personal build — built with a 5-person team; the CLI and GUI shown here are my own follow-on build.

smart_safe.ino Embedded Systems

Smart Safe Hardware Retrofit

solo build

Retrofitted a real commercial safe into a contactless access-control system. An RC522 RFID module replaces the mechanical lock for authentication, while an MPU-6050 accelerometer/gyroscope runs real-time tamper detection — flagging unauthorized tilting, movement, or forced entry attempts as they happen.
